You are picking the next docs item to implement from **Tier 5 (the
docs queue) of `IMPLEMENTATION_PLAN.md`** (root of the repo). There
is no separate docs plan file — `DOCS_IMPLEMENTATION_PLAN.md` was
merged into Tier 5 on 2026-08-08.

## Step 1 — pick

Read Tier 5 of `IMPLEMENTATION_PLAN.md`. Items appear in priority
order within the tier (migrated D-coded items and P-coded items are
equals — position decides).

Pick the first item not marked `[x]` that is not `BLOCKED` on an
open code item. Spot-check the cited docs page to confirm the gap
still exists before delegating.

Never pick an item that requires a `src/` or `tests/` change — if
you find one in Tier 5, it is misfiled; surface it to the operator
for refiling into a code tier instead of working it.

## Step 2 — confirm

State to the operator, in one line, which item you picked and the
canonical docs page that will change (e.g. "Tier 5 — stale
'Not Yet Implemented' claims in
`docs/user-guide/regulatory/basel31.md` — P4.29").

## Step 4 — commit (top level, not via an agent)

Once doc-writer reports the build is clean:

1. Run `git status` and review the diff. Confirm changes are
   confined to `docs/`.
2. Update `IMPLEMENTATION_PLAN.md` at the top level using the Edit
   tool: toggle the Tier 5 item from `[ ]` to `[x]` with a one-line
   resolution summary. This is a single-line tick — do not invoke
   `plan-curator` for it.
3. Append a one-line `docs/appendix/changelog.md` entry capturing
   the why (regulatory citation, what was wrong, what was fixed).
4. Stage, commit, push to the current branch with a message
   `docs(<area>): <one-line summary>`.

## Constraints

- One docs item per invocation. Do not chain.
- If doc-writer reports the item is actually a code bug (docs
  right, code wrong), stop and instruct the operator to refile the
  bullet into the matching code tier. Do not edit `src/` from this
  command.
- If `uv run zensical build` keeps failing despite the writer's
  attempts, surface the build error and stop — do not commit a
  broken site.
- If Tier 5 has no open unblocked items, report so and stop.
