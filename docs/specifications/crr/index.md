# CRR Specifications

Formal specifications for the UK CRR credit risk framework — Regulation (EU) No 575/2013 as
onshored, read with the PRA Rulebook (CRR Firms) — in force until 31 December 2026.

From 1 January 2027 the [Basel 3.1 specifications](../basel31/index.md) apply. They document only
what PRA PS1/26 **changes**, so the pages below remain the authoritative reference for every rule
that Basel 3.1 leaves unchanged.

**Primary Regulatory Source:** UK CRR (EU 575/2013 as onshored); PRA Rulebook (CRR Firms)

## Relationship to Basel 3.1

- Where a [Basel 3.1 specification](../basel31/index.md) shares its name with a page above, it
  documents only the changes; for anything it does not mention, the CRR page still applies.
- **Supporting Factors** have no Basel 3.1 equivalent: both factors are removed from
  1 January 2027.
- **Credit Conversion Factors** carry the Basel 3.1 values in comparison tables on the CRR page
  itself, since the structure is unchanged.
- **SA-CCR** is inherited by Basel 3.1 almost unchanged; the
  [Basel 3.1 CCR page](../basel31/ccr.md) records the differences.

See also [CRR vs Basel 3.1](../../framework-comparison/index.md).
